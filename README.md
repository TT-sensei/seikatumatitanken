# まちたんけん！

架空の「みどりのまち」を歩いて探検し、施設ごとのミッションを通して生活科を自学自習するブラウザアプリです。

## 起動
GitHub Pagesで公開する場合は、リポジトリの Settings → Pages で main ブランチの root を指定します。ローカルでは index.html をブラウザで開いてください。

## できること
- 川、橋、道路、住宅地、公園、畑が広がるイラスト地図を探検
- 地図の施設マーカーを選ぶと、歩くルートと現在地がアニメーションで表示
- 施設に到着すると、その場所の説明とミッションを表示
- ミッションに正解するとポイントと発見ノートを獲得
- 訪れた場所、現在地、クリア状況を同じ端末のブラウザに保存

## ファイル構成
- index.html：画面の骨組みと地図のSVG
- css/style.css：見た目、レスポンシブ表示、歩行・ルートアニメーション
- js/data/places.js：町の施設データ
- js/data/missions.js：ミッションデータ
- js/app.js：地図操作、移動、進行、保存の処理

## 拡張方法
### 施設を増やす
js/data/places.js の TOWN_PLACES に追加します。idは重複させず、x/yは地図上の位置（0〜100）です。マーカーはこの座標に表示されます。

### ミッションを増やす
js/data/missions.js の TOWN_MISSIONS に追加します。placeIdを施設のidと一致させると、その施設のミッションになります。問題・選択肢・正解・ヒント・解説・報酬をデータとして管理しています。

## 保存
localStorageに進行状況を保存します。同じブラウザ・同じ端末で続きから遊べます。別の端末やブラウザには自動で引き継がれません。

## 開発方針
静的HTML/CSS/JavaScript。外部API・バックエンド・ビルド工程・外部画像に依存しません。既存のTT-senseiアプリとは独立して開発します。
