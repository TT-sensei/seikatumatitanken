# まちたんけん！

架空の町を探検し、施設ごとのミッションを通して生活科を自学自習するブラウザアプリの試作版です。

## 起動
GitHub Pagesで公開する場合は、リポジトリの Settings → Pages で main ブランチの root を指定します。ローカルでは index.html をブラウザで開いてください。

## ファイル構成
- index.html：画面の骨組み
- css/style.css：見た目
- js/data/places.js：町の施設データ
- js/data/missions.js：ミッションデータ
- js/app.js：表示・進行・保存の処理

## 拡張方法
### 施設を増やす
js/data/places.js の TOWN_PLACES に追加します。idは重複させず、x/yは地図上の位置（0〜100）です。

### ミッションを増やす
js/data/missions.js の TOWN_MISSIONS に追加します。placeIdを施設のidと一致させると、その施設のミッションになります。問題・選択肢・正解・ヒント・解説・報酬をデータとして管理しています。

### 今後の拡張候補
1. 施設の中に入る個別画面
2. 町の人との会話イベント
3. 観察・並べ替え・選択・実体験などのミッション形式
4. 発見図鑑の詳細ページ
5. 季節や時間帯による町の変化
6. ミッションの複数段階化・解放条件
7. ナビアンの案内とヒント

## 保存
localStorageに進行状況を保存します。同じブラウザ・同じ端末で続きから遊べます。

## 開発方針
静的HTML/CSS/JavaScript。外部API・バックエンド・ビルド工程なし。既存のTT-senseiアプリとは独立して開発します。
