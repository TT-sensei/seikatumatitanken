# まちたんけん！

架空の「みどりのまち」を歩いて探検し、施設・自然・安全・人々のくらしなどを自分で発見する生活科向けブラウザアプリです。

## 起動
GitHub Pagesで公開する場合は、リポジトリの Settings → Pages で公開元を指定します。ローカルでは index.html をブラウザで開いてください。

## できること
- 川、橋、道路、住宅地、公園、畑が広がるイラスト地図を探検
- 施設だけでなく、草むら・大きな木・横断歩道・道路・ごみ置き場・畑などにも移動
- 施設探検／自然・生きもの探検／交通・安全探検／町のひみつ探検／人・くらし探検／公園・遊び探検／環境・エコ探検
- クイズに答えるだけでなく、観察・比較・考えたことを自分の言葉で記録
- 分野ごとのミッション絞り込み
- 発見ノートにゲーム内の記録と、自分の町で見つけたことを保存
- 進みぐあい、現在地、記録を同じ端末のブラウザに保存

## ファイル構成
- index.html：画面の骨組みと地図のSVG
- css/style.css：見た目、レスポンシブ表示、歩行・ルートアニメーション
- js/data/places.js：施設・発見ポイント
- js/data/missions.js：ミッションデータ
- js/app.js：地図操作、移動、進行、記録、保存

## 拡張方法
### 探検ポイントを増やす
js/data/places.js の TOWN_PLACES に追加します。idは重複させず、x/yは地図上の位置（0〜100）です。categoryはミッションの分野名とそろえます。

### ミッションを増やす
js/data/missions.js の TOWN_MISSIONS に追加します。placeIdを探検ポイントのidと一致させます。
- type: quiz / compare は選択式
- type: observe / think は自由記述式
- answerは選択肢の0始まりの番号。自由記述式ではnull
- choices、hint、explanation、rewardを設定

## 保存
localStorageに進行状況を保存します。同じブラウザ・同じ端末で続きから遊べます。別の端末やブラウザには自動で引き継がれません。既存の保存キーを引き継ぐため、これまでのクリア状況やポイントも維持されます。

## 開発方針
静的HTML/CSS/JavaScript。外部API・バックエンド・ビルド工程・外部画像に依存しません。
